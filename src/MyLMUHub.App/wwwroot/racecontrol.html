Race Control

The live dashboard for your second screen. Set it up here; moving and resizing widgets and each widget's own settings stay in the dashboard (press E there).

VE goal per track

The fuel widget colours your VE use against it: green well under, yellow cutting close, red (flashing) over. Only the goals set here are used.

Theme

The look of the dashboard (all views). Single colours and fonts: the Theme button in the dashboard's edit mode.

Views

Several layouts (e.g. driving, spectating). The dashboard always fills its window: on another kind of screen (ultrawide, portrait) a view gets its own arrangement by itself. New, rename and delete: in the dashboard's edit mode.

Hotkeys

Switch views while you drive. Click Set, then press a key (letters, digits, F1-F24 or numpad, with Ctrl / Alt / Shift) or a button on your wheel, button box or gamepad. Pick one the game does not use, e.g. Ctrl+Alt+1. Esc = cancel. They work while the dashboard is open.

Network

Open the dashboard in a browser on another PC, laptop or tablet at home (same views, live). My LMU Hub has to run on this PC.
